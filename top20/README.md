# 北美量子化学 / 计算化学 Top 20 学者

`site/index.html`：总览（排名表、产出—影响力散点、方向构成、20 张档案卡）+ 每位学者的详细页（`#<OpenAlex 作者 ID>`）：研究综述、代表性贡献、发表与被引时间线、方向构成、常用期刊、主要 / 近期论文、合作机构与个人合作网络图。

排名 = 0.4 × 语料被引总数百分位 + 0.2 × h 指数百分位 + 0.2 × 语料论文数百分位 + 0.2 × 网内合作者数百分位（在北美地图全部 1,044 位 PI 中计算）。

数据由 [`../analysis/build_atlas_data.py`](../analysis/build_atlas_data.py) 生成；研究综述是人工撰写的 `data/manual/profiles.json`。
